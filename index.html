STEP 1

자료 첨부·분석

홍보용 PDF와 PPTX를 올리면 제목·핵심 문장·수치·검사 정보(검체, 일정, 소요시간, 검사코드, 수가)를 자동으로 뽑아 표로 정리합니다.

STEP 2

1페이지 홍보물 생성

분석 결과로 A4 한 장짜리 홍보물을 만듭니다. 내용을 직접 고치고 PDF · PPTX · PNG로 저장할 수 있습니다.

STEP 3

학술교육 · 영업화법예시

교육자료(홍보물·화법지)를 한 곳에 모아 보고, 원장님 상담 교육용 영업화법예시를 5단계 시간대 흐름으로 만들어 이미지·PDF로 추출합니다.

STEP 4

제안서 작성

거래처 상황과 승인 단가 조건을 입력하면 근거·검체·운영 정보를 반영한 제안서 초안을 만들고 Word/PDF로 저장합니다.

    1. 월별 엑셀 첨부

    월별 파일을 2개 이상 선택하세요. C열=검사명, D열=건수는 고정으로 읽고, 파일명에 2026-08, 2026년 8월 또는 2025-01-01 ~ 2025-12-31처럼 기간이 있으면 자동 인식합니다. 전년 연간 파일과 올해 월간 파일을 함께 넣으면 전년 대비 신규·기존 항목을 집계합니다.

    선택된 파일이 없습니다.

    파일은 서버로 전송되지 않고 이 브라우저에서만 분석합니다. XLSX 파일은 첫 번째 데이터 시트를 읽습니다. 구형 .xls는 Excel에서 .xlsx로 다시 저장해 주세요.

    월별 파일을 선택해 주세요.

    거래처별 검사 항목 비교

    상태는 최신 월과 바로 이전 월을 비교합니다. ‘신규’는 최신 월에 처음 확인된 조합, ‘중단’은 이전 월에는 있었으나 최신 월에 없는 조합입니다.

    사용 안내

    업무에 바로 쓰기 전에 한 번 확인해 주세요.

    작업 순서

    1. 자료 첨부·분석 : 재단에서 받은 PDF · PPTX를 올리고 ‘자료 읽고 분석하기’를 누릅니다.
    2. 결과 확인 : 추정 제목, 핵심 문장, 수치, 검사 정보 표를 확인하고 필요하면 원문을 직접 고쳐 다시 분석합니다.
    3. 1P 홍보물 : ‘자료에서 자동 채우기’로 초안을 만들고 문구를 다듬은 뒤 PDF · PPTX · PNG로 저장합니다.
    4. 학술교육 : 교육자료실에서 산출물을 모아 보고, ‘영업화법예시’에서 5단계(0:00~5:00) 시간대별 교육용 화법지를 만들어 이미지(PNG)·PDF로 추출합니다.
    5. 제안서 : 승인 단가와 할인율을 입력하고 초안을 만든 뒤 Word 또는 PDF로 저장합니다.
    6. 숙성항목 : 거래처별 월간 항목 엑셀을 2개월 이상 첨부해 신규·중단 검사와 건수 증감을 비교합니다.

    파일 처리와 저장 방식

    • PDF · PPTX 파일은 브라우저 안에서만 열어 읽습니다. 서버 업로드나 외부 전송이 없습니다.
    • 추출한 텍스트, 이미지, 홍보물·교육화법 초안은 이 브라우저(로컬 저장소)에 보관됩니다. 브라우저 데이터를 지우거나 다른 기기를 쓰면 사라지므로, 완성본은 파일로 저장해 두세요.
    • 이미지 추출은 용량이 큽니다. 많이 넣으면 분석이 느려지므로 필요한 자료만 첨부하는 편이 좋습니다.

    꼭 확인할 사항

    • 자동 추출은 초안입니다. 검사 항목, 검체 조건, 검사 일정, 검사코드, 수가·급여 기준은 원문과 최신 공지를 반드시 대조하세요.
    • 교육 화법지의 근거 수치는 첨부 자료에 적힌 값만 사용합니다. 자료에 없는 효능·조건·비교 우위는 임의로 만들지 마세요.
    • 원장님 상담에서는 완치 · 100% · 부작용 없음 · 최고 · 유일 같은 단정 표현을 쓰지 않습니다. 진단과 치료 결정은 담당 의료진의 판단에 따릅니다.
    • 첨부 자료에 없는 할인율·계약 조건·검사 효과는 임의로 만들지 않습니다. 승인된 조건만 입력해 주세요.
    • 환자 개인정보가 담긴 파일은 첨부하지 마세요. 홍보물·교육화법에는 개인정보·내부 단가표를 넣지 않도록 확인하세요.
    • 구형 .ppt(파워포인트 97-2003) 형식은 읽을 수 없습니다. PPTX로 저장한 뒤 첨부해 주세요.
